# Tracker Tool 測試版 — 工作站簡短測試（約 10 分鐘）

## 這次要確認什麼

這是 Tracker Tool v1.1.0 的**測試版**。它和正式版的唯一差別：測試版不再附帶 Microsoft Visual C++ runtime，而是使用電腦上已安裝的 Microsoft 官方版本。

請確認它能在你的工作站正常開啟並轉換。介面和操作方式都與正式版相同。

## 請先注意

- **這是測試版，只用於這次測試。** 正式工作請繼續使用 v1.1.0 正式版。
- **不要解除安裝**電腦上任何「Microsoft Visual C++ … Redistributable」，其他軟體可能需要它們。
- 沒有安裝、或版本低於 14.44 時，**不要自行安裝**，先依步驟 1 記錄下來並告訴維護者。
- 測試結果請另存到新資料夾，不要覆蓋正式的檔案。

---

## 步驟

### 1. 記錄 Redistributable 版本

1. 開啟 **設定 → 應用程式 → 已安裝的應用程式**，搜尋 `Visual C++`。
2. 記下所有 **x64** 項目的名稱與版本，例如 `Microsoft Visual C++ 2015-2022 Redistributable (x64) 14.44.35211`。
3. 判斷：
   - 有 x64 版本 **14.44 或更新**：繼續步驟 2。
   - 沒有，或版本較舊：仍可做步驟 2，看程式能不能開啟並記錄結果；**不要做步驟 3**，並告訴維護者。

### 2. 開啟測試版

1. 把整個 `TrackerTool` 測試版資料夾複製到本機磁碟，例如桌面。不要直接從網路磁碟執行。
2. 執行 `TrackerTool\TrackerTool.exe`。
3. 確認：
   - 視窗正常開啟；
   - 下方狀態列顯示 `tracker-tool 1.1.0`。
4. 若出現錯誤視窗，請截圖。

### 3. 轉換一次並比對

1. 選一顆你**已經用正式版 v1.1.0 轉換過**的 shot，用相同的來源檔與設定再轉換一次：
   - Software、Role、Width、Height、Start / End frame 都相同；
   - 輸出到新的資料夾。
2. 結果應顯示 `PASS`。
3. 比對兩個輸出檔是否完全相同：
   1. 在輸出資料夾的網址列輸入 `cmd` 後按 Enter；
   2. 輸入以下指令（檔名換成你的）：

   ```text
   fc /b "正式版輸出.txt" "測試版輸出.txt"
   ```

   - 只顯示一行「找不到相異處」之類的訊息（英文系統為 `no differences encountered`），沒有列出任何位址與數值：完全相同。
   - 列出一串位址與數值：兩個檔案不同，請在回報中註明。
4. 不需要匯入目標軟體，除非兩個檔案不同。


若有任何 FAIL，請一併按程式中的 `Copy diagnostics`，把內容貼在回報裡。
