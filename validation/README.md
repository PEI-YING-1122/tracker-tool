## Notes

- Target-software setup matters. The camera plate must cover the full production frame range of the converted tracks (V1: 1001–1050), and the plate resolution must equal the conversion resolution (Same Image Geometry, `docs/INTERCHANGE_MASTER.md` §7). Both setup errors were seen once in the session, and both imports passed after correction. Neither is a Core defect.
- "Visually normal" is a visual check, not an exact per-observation verification.
